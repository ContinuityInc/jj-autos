# JJ Autos

Owner-operated performance car rental website for JJ Autos in Cupertino,
California. The responsive showroom features interactive 3D presentations of a
Chevrolet Corvette C8 2LT, BMW 840i, and Tesla Model S Plaid, plus a rental
request flow.

## Local development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
pnpm lint
pnpm build
```
